# gravitywell

A typed Python client for the [Pi-hole](https://pi-hole.net) v6 REST API, built on [ClientX](https://github.com/slatecipher/ClientX).

gravitywell is a third-party application. It is not made, endorsed or supported by the Pi-hole project.

> **Status:** pre-alpha, with nothing usable yet.

## Planned

- Sync and async clients, with Pydantic models for responses.
- Login and sessions handled for you, with a Pi-hole application password.
- The Pi-hole's operations as tools for AI models, and an MCP server.

gravitywell supports Pi-hole v6 only: v5's API is a different interface.
